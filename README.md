# margee-midia

Hospedagem pública de mídia do Instagram do [Margee](https://margee.com.br),
sistema de gestão financeira para restaurantes.

Os arquivos daqui são servidos por CDN e consumidos pela ferramenta de
agendamento das publicações. Não há código de aplicação neste repositório.

## Estrutura

- `reels/` vídeos verticais 1080x1920 publicados como Reels

## Uso

Os arquivos são servidos pelo jsDelivr:

```
https://cdn.jsdelivr.net/gh/Hoelyntoon/margee-midia@<commit>/reels/<arquivo>
```
